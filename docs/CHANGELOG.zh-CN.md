# 纯黑浏览 · Pure Black 1.8.1

适用于桌面版 Chrome / Edge 的 Manifest V3 扩展。将整页背景统一为用户选择的颜色，默认纯黑；保留照片、视频和有色按钮。无需开启 HDR，无联网请求或统计，设置只保存在本机。

## 安装和更新

1. 打开 edge://extensions 或 chrome://extensions，开启开发者模式。
2. 点击“加载解压缩的扩展程序”，选择本目录 Pure-Black-Extension，直接包含 manifest.json 的文件夹。
3. 如果已安装，点击该扩展的“重新加载”，确认版本为 1.8.1，再刷新网页。更新 ZIP 文件本身不会更新已加载的扩展目录，须先解压覆盖。
4. 工具栏图标应为小月亮。若仍是“纯”字，说明浏览器仍使用旧文件或旧版本：在扩展详情确认版本和加载目录。无需删除扩展或清除设置。

## 操作

- Alt+Shift+D 切换全局开关。保留各网站的单独启用设置。
- 如果浏览器未分配快捷键，普通网页内有备用响应。网页内备用响应需要焦点在网页中；地址栏、扩展商店、内置页面等应使用浏览器原生快捷键。
- 弹窗右上角显示实际绑定情况，点击可打开浏览器的快捷键设置。若被其他程序占用，需解除冲突或重新绑定。
- 开启时工具栏和弹窗显示睁眼微笑的小月亮，关闭时显示闭眼休息的小月亮。
- 可按主机名关闭该站，子域名分别保存；跨域嵌入页面使用自身主机名的设置。
- 背景调色盘提供纯黑、炭黑、石墨、午夜蓝、松林绿、暖墨六个预设。也可使用取色器或输入完整的 #RRGGBB 色值。
- “黑色程度”滑块从明亮到深黑；100% 为纯黑，0% 为白色。滑动过程中保留当前色相，选择新的颜色时同步更新明暗程度。
- 调整后自动保存，并直接通知当前网页立即应用。选色时自动开启配色并启用当前网站，便于预览。较亮的自选背景使用深色文字，较暗背景使用浅色文字，保留原本已有足够对比度的文字颜色。
- “干净的黑色”一栏已移除；继续沿用之前保存的阴影设置，新安装默认移除背景阴影，并保留小型图标使用的阴影。

## 1.8.1 更新

修复黑白灰背景渐变残留，包括 Chrome“新变化”内容页底部轮播栏的灰色光晕。普通背景使用所选底色，伪元素渐变遮罩移除后保留透明，避免遮住轮播卡片。彩色渐变、渐变文字及包含图片的背景保留，关闭后恢复原样。

## 1.4 更新

增加背景调色盘、自选颜色、色值输入和黑色程度滑块。移除阴影设置行。小月亮移到标题左侧，为调色盘留出空间。自选背景同步应用于普通背景、伪元素背景和有道装饰背景，关闭后恢复网站原样。

## 1.5 更新

快捷键及弹窗开关切换后显示约两秒的提示；受保护页面使用工具栏 ON/OFF 短暂标记作为替代。选色增加当前网页的直接应用及响应确认；若网页仍运行旧版脚本，弹窗明确提示刷新网页，不再误报已应用。工具栏图标重新裁切，减少透明留白，尽量填满浏览器允许的图标区域，弹窗里的 Logo 比例保持不变。

## 1.6 更新

文字按所在区域实际的纯色或渐变背景选择深浅颜色，保留原本有足够对比度的文字；阻止祖先元素的浅色文字渗入浅色按钮。未知照片背景保留原文字，透明 SVG 虚线边框则按透明背景处理。为背景合并后失去边界的大块卡片和面板增加 1px 内侧轮廓线，不改变布局尺寸，关闭时完整还原。切换提示改到页面顶部居中，约两秒后消失。

## 1.3 更新

去掉页面配色选择，固定整页纯黑，即使旧设置选择了深灰模式也自动使用整页纯黑。快捷键增加网页事件备用路径和重复事件去重，弹窗展示真实绑定状态。工具栏配置 16/32/48/128 像素的两套原创小月亮图标。有道翻译单独处理工作区的浅色装饰背景图，保留普通图片。

## 边界与验证

扩展修改网页配色，不修改浏览器标签栏、Windows HDR、图片和视频内部的黑位。LCD 背光及面板设置决定最终实际黑位。保留一般背景图片和渐变；有道已知的装饰背景图除外。暂不处理 Shadow DOM、canvas 内部画面及图片中的文字。特殊样式可能需要按网站适配。

动态页面最多约每 700 毫秒重新计算样式，复杂页面会产生额外开销，首次载入可能短暂显示原色。

qa/browser-qa.cjs 使用真实浏览器按键和模拟扩展 API，验证内容脚本、快捷键备用路径、设置存储、图标同步、箭头透明边框及关闭恢复。qa/youdao-qa.cjs 访问有道真实页面验证背景修复及还原。测试不替代用户浏览器中实际加载扩展和系统快捷键绑定检查。

## 1.6.1 更新

修复选择松林绿后再选纯黑，拖动黑色程度仍出现绿色的问题。显式选择纯黑或白色会清除旧色相，滑块只产生中性灰色。单独将彩色滑块拖到最黑再拖回，仍保留该颜色。

## 1.7 更新

删除文字切换提示框，改为约 1.5 秒的整页拉灯动画：顶部灯泡落下，拉绳下拉回弹，灯泡随深色启用熄灭、随深色关闭点亮，并配合整页暗幕、暖光和光束。配色在拉绳动作中段切换，结束后整个动画层自动移除。动画不拦截鼠标操作；快速反向切换会取消旧动画并保持最后选择。更改颜色且启用状态不变时立即预览，不播放拉灯动画。

## 1.7.1 更新

根据用户明确希望播放动画的选择，不再因系统“减少动态效果”设置而完全跳过拉灯效果。灯泡使用 DOM/SVG namespace API 和构造样式表创建，兼容 Trusted Types 及禁止内联样式标签的网页。

为小型黑白 SVG 图标增加反色，保留轮廓与内部黑白细节，彩色图标不处理。给可读取像素的透明底深色 PNG 小图添加柔和浅色轮廓，不改变原图像素和颜色；不处理不透明照片。音乐理论网站的外部页脚黑猫资源单独使用同样的轮廓效果，避免跨域像素读取。关闭后移除这些效果，还原图标。

## 1.8 更新

切换动画更换为与 Logo 一致的可爱太阳和月亮：柔和配色、圆润表情、腮红、小星星。进入深色时太阳落下、月亮升起，退出深色时反向切换；不再显示灯泡和灯绳，动画约 1.4 秒，期间可继续操作网页。

修复带 CSS transition 的标题在重复检测后变黑的问题。检测时临时停止元素颜色过渡，按稳定原色判断对比度，完成后立即恢复网页原有的 transition 样式。在音乐理论网站的“关于规则的存在”标题上验证了滚动及重新检测后的可读性。
